# Changelog

Each release's changes are in [`crate/CHANGELOG.md`](crate/CHANGELOG.md).

- **0.4.0 (17 October 2026):** live capture in every copy, the ready-built downloads included, with no Npcap SDK needed to build; alert and metrics logs to CSV; the crate moved to `crate/` for good.
- **0.3.1 (15 October 2026):** the first public Community release, under GPL-3.0-only, with ready-built downloads for Windows, macOS and Linux.
- **0.3.0 (30 September 2026):** rebuilt from the v0.2 ASCII mapper as a new crate, with the program `mdd`.
